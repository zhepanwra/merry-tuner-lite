# merry-tuner-lite

I build things, like @pretalx or @venueless. I run events, like @metarheinmain or @c3cashdesk.

拿来练手的小仓库

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/merry-tuner-lite.git
cd merry-tuner-lite
npm install
```
